TCG Market Research Dashboard

Private internal analytics application for trading card collectibles market research

IMPORTANT: This is a public informational page only. The actual analytics dashboard is a private internal research tool and is not publicly accessible.

Application Purpose

This application performs advisory market research on trading card collectibles. It is a private, internal analytics tool — not a public marketplace, resale platform, checkout application, affiliate shopping app, seller tool, or automated buying/selling system.

Covered Collectibles

  • Pokémon Trading Card Game
  • Magic: The Gathering
  • One Piece Card Game
  • Lorcana
  • Similar trading card game (TCG) products

What the Application Does NOT Do

  • Does not buy, sell, bid, or list items
  • Does not manage inventory or orders
  • Does not perform checkout or payment processing
  • Does not scrape eBay pages, bypass rate limits, or redistribute eBay data
  • Does not resell or expose eBay data to third parties
  • Is not a public API — all data is used internally for advisory research only

eBay API Usage

The application uses eBay APIs for low-volume, targeted market research queries only:

  • Browse API — active listing research
  • Marketplace Insights API — restricted access requested, not approved or in use; proposed historical sold-item research via
    GET /buy/marketplace_insights/v1_beta/item_sales/search
    scope: buy.marketplace.insights

Data & Privacy

eBay data is used internally for advisory research only. It is not exposed as a public API and is not sold or resold to third parties. No user data, PII, or personally identifiable information is collected by the informational page you are viewing now.

Application Details

The Application URL is a public informational page describing the private internal research application. The actual analytics dashboard is not publicly accessible because it is an internal research tool.
